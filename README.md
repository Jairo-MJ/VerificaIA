# VerificaIA

Descripción general

VerificaIA sería una aplicación web que guía a los usuarios para evaluar información potencialmente engañosa encontrada en Internet o redes sociales.

1. Problema

Actualmente, la Inteligencia Artificial permite generar textos, imágenes, audios y videos que pueden parecer reales. Esto facilita la creación y difusión de contenido falso o engañoso en redes sociales y otros medios digitales.
Muchas personas comparten información rápidamente sin verificar su fuente, fecha o confiabilidad, lo que contribuye a la propagación de la desinformación.
Aunque existen diferentes métodos para comprobar información, no todos los usuarios conocen un proceso sencillo que les permita analizar un contenido antes de compartirlo.

2. Objetivo general

Objetivo general

Desarrollar una aplicación web que guíe a los usuarios en el proceso de verificación de información digital mediante un conjunto de criterios y pasos interactivos para promover una evaluación responsable del contenido antes de compartirlo.

Objetivos particulares

Diseñar una interfaz web que permita al usuario registrar una información o contenido que desea analizar.
Implementar una guía interactiva basada en criterios de verificación, como la revisión de la fuente, fecha de publicación y comparación con otras fuentes.
Generar una evaluación orientativa a partir de las respuestas proporcionadas por el usuario durante el proceso de verificación.
Registrar los análisis realizados para permitir la consulta de resultados anteriores.

3. Alcance

El proyecto contemplará:
Una aplicación web.
Registro e inicio de sesión de usuarios.
Registro de información o contenido que el usuario desea analizar.
Un proceso guiado de verificación.
Preguntas relacionadas con:
Fuente de la información.
Fecha de publicación.
Comparación con otras fuentes.
Posibles señales de contenido generado o manipulado mediante IA.
Generación de una evaluación orientativa.
Historial básico de análisis realizados por el usuario.

4. Fuera de alcance

El proyecto inicialmente no contemplará:
Determinar automáticamente si una noticia es verdadera o falsa.
Detectar deepfakes profesionales mediante modelos avanzados de IA.
Analizar automáticamente videos o audios.
Verificar toda la información disponible en Internet en tiempo real.
Sustituir a periodistas, verificadores profesionales o expertos.
Integrarse inicialmente con todas las redes sociales.
 
5. MVP

Una aplicación web funcional en la que un usuario pueda ingresar una afirmación o información que desea verificar y completar una guía interactiva con preguntas sobre la fuente, fecha y comparación con otras fuentes. Al finalizar, el sistema mostrará una evaluación orientativa y recomendaciones sobre los siguientes pasos antes de compartir la información.

6. Problema y objetivo

Problema

La difusión de información falsa o engañosa, especialmente aquella generada mediante inteligencia artificial, dificulta que las personas identifiquen contenido confiable. VerificaIA busca orientar a los usuarios en el proceso de verificación de información mediante una guía interactiva.
